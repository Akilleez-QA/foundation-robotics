# Support

- Questions and problems: open a GitHub issue with the problem-report template. Include the command you ran, the output and the commit.
- New capabilities or behaviour changes: use the change-request template.
- Security problems: report privately as described in [SECURITY.md](SECURITY.md).
- Commercial licensing questions: craig@nh3.biz.

Before opening an issue, check the [how-to guides](docs/guides/how-to/README.md#troubleshoot-an-error) and the [error table](docs/icd/icd-cstack.md#4-errors-and-result-semantics).
